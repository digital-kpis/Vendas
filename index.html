Participação iFood/Assaí — comparativo mensal

Relatório Diário: as células de venda bruta (Assaí e iFood) e pedidos são editáveis: clique e digite o novo valor (basta digitar o número, ex: 950000,50 — o "R$" é aplicado automaticamente ao sair da célula). Se você apagar o conteúdo de uma célula, ela é zerada automaticamente. As células com 🔒 (participação e ticket médio) são calculadas automaticamente e não podem ser editadas. Use o campo Mês/Ano para trocar o mês exibido — o calendário se ajusta sozinho (dias e dias da semana corretos do mês escolhido). Resumo Anual: mostra a soma de todas as vendas de cada mês do ano selecionado (é somente leitura — os valores vêm dos dados lançados na aba Relatório Diário). Use o campo Ano para trocar o ano exibido, podendo selecionar o ano vigente. Use Tab / Shift+Tab para navegar entre as células com o teclado.

Lançamento rápido: pressione Enter ou as setas ↓ / ↑ para pular para a mesma coluna no dia seguinte/anterior sem usar o mouse. Você também pode colar uma coluna de valores copiada do Excel diretamente numa célula: os valores são distribuídos automaticamente dia a dia a partir da célula focada. Os dados são salvos automaticamente no navegador (veja o indicador ao lado dos botões) — use Exportar backup (JSON) periodicamente para guardar uma cópia de segurança, e Importar backup para restaurar ou mesclar dados de outro computador. Exportar CSV gera uma planilha do mês exibido, compatível com Excel/Google Sheets.

Novidades: use ↩️ Desfazer (ou Ctrl+Z) para reverter a última edição. Células destacadas em amarelo indicam um valor fora do padrão comparado à média dos últimos dias — vale conferir se não é erro de digitação. Defina uma meta mensal para acompanhar o progresso com a barra abaixo do resumo. O log de edições mostra quem alterou o quê e quando. Em 🔗 Sincronização entre dispositivos você pode conectar um banco Firebase Realtime Database (gratuito) para acessar os mesmos dados do celular e do computador — sem configurar, o relatório continua funcionando normalmente, salvo apenas neste navegador. Na aba Resumo Anual, um gráfico mostra a evolução da participação iFood/Assaí mês a mês.
